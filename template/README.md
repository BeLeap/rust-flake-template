# Rust project

This project was created from [BeLeap/rust-flake-template](https://github.com/BeLeap/rust-flake-template).

Enter the development shell with:

```sh
nix develop
```

If you use direnv, run `direnv allow` once. The shell will then load
automatically when you enter the project directory.

Run the starter program with `cargo run`, format the code with `cargo fmt`, and
build the Nix package with `nix build`.
